# Référentiel de compétences (seed du J1)

> Liste initiale chargée au lot L2. Rédigée d'après les programmes du collège (cycles 3 et 4), pour des élèves de 12 ans (6e/5e).
> ✅ **Validé par le tuteur le 2026-10-12** (Q4). Il le fera évoluer dans l'application : ajouter, renommer, archiver une compétence.
> Chaque question d'épreuve est liée à une ou plusieurs de ces compétences ; c'est ce qui alimente le suivi « par compétence » des parents.

## Mathématiques

### Nombres et calculs (arithmétique)

| Code | Compétence |
|---|---|
| NUM-01 | Comparer, ranger et encadrer des nombres entiers et décimaux |
| NUM-02 | Poser et effectuer les quatre opérations (entiers et décimaux) |
| NUM-03 | Calculer mentalement et estimer un ordre de grandeur |
| NUM-04 | Appliquer les priorités opératoires et utiliser les parenthèses |
| NUM-05 | Comprendre, comparer et simplifier des fractions |
| NUM-06 | Additionner, soustraire et multiplier des fractions |
| NUM-07 | Utiliser les nombres relatifs (repérage, addition, soustraction) |
| NUM-08 | Reconnaître multiples et diviseurs, utiliser les critères de divisibilité, les nombres premiers |
| NUM-09 | Reconnaître et utiliser une situation de proportionnalité, calculer un pourcentage |
| NUM-10 | Résoudre un problème en plusieurs étapes |

### Espace et géométrie

| Code | Compétence |
|---|---|
| GEO-01 | Utiliser le vocabulaire et les notations (point, droite, segment, demi-droite, milieu) |
| GEO-02 | Tracer des droites perpendiculaires et parallèles |
| GEO-03 | Tracer des cercles et utiliser le compas pour reporter des longueurs |
| GEO-04 | Nommer, mesurer et construire un angle |
| GEO-05 | Connaître les propriétés des triangles et les construire |
| GEO-06 | Connaître les propriétés des quadrilatères (carré, rectangle, losange, parallélogramme) |
| GEO-07 | Construire le symétrique d'une figure (symétrie axiale et centrale) |
| GEO-08 | Utiliser la somme des angles d'un triangle et l'inégalité triangulaire |
| GEO-09 | Se repérer dans le plan (coordonnées) |

### Grandeurs et mesures (système métrique)

| Code | Compétence |
|---|---|
| MES-01 | Convertir des longueurs (mm, cm, dm, m, dam, hm, km) |
| MES-02 | Convertir des masses (mg, g, kg, t) et des capacités (mL, cL, dL, L) |
| MES-03 | Calculer le périmètre d'un polygone et d'un cercle |
| MES-04 | Calculer des aires (rectangle, triangle, disque) et convertir des unités d'aire |
| MES-05 | Calculer des volumes (pavé, cube) et faire le lien entre cm³, dm³ et L |
| MES-06 | Calculer des durées et convertir des unités de temps |

## Initiation à l'informatique

| Code | Compétence |
|---|---|
| INF-01 | Distinguer matériel et logiciel ; organiser fichiers et dossiers |
| INF-02 | Comprendre ce qu'est un algorithme (une suite d'instructions précises) |
| INF-03 | Écrire une séquence d'instructions pour atteindre un but |
| INF-04 | Répéter des instructions avec une boucle |
| INF-05 | Prendre une décision avec une condition (si… alors… sinon) |
| INF-06 | Mémoriser une valeur dans une variable |
| INF-07 | Trouver et corriger une erreur dans un programme (déboguer) |
| INF-08 | Protéger ses comptes et ses données personnelles sur Internet |

Les compétences INF-02 à INF-07 seront surtout évaluées avec les exercices de programmation par blocs (J3) ; au J1, elles le sont par des QCM, des réponses courtes et des schémas sur le cahier virtuel.
