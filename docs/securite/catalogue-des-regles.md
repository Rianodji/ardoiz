## Convention de traçabilité dans le code

- Le code qui garantit une règle la cite en commentaire, avec la menace : `// Réponses attendues jamais exposées à l'élève (R5, M6).`
- Le test correspondant porte la même référence dans son nom : `it("ne renvoie jamais la réponse attendue à l'élève (R5)")`.
- Quand le gardien est codé, la colonne « Gardien dans le code » reçoit le chemin et le nom exacts (`apps/api/src/assessment/domain/attempt.ts › Attempt.submit`) et l'état passe à ✅ quand le test est vert en CI.
