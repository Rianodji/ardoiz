# ADR-0009 : Une gamification éthique, sans classement ni pression

## Statut
Acceptée · cadrage du 2026-10-11

## Contexte
Le porteur veut de la gamification pour motiver les élèves. Ce sont des enfants : les recommandations de conception adaptée à l'âge (CNIL, Age Appropriate Design Code britannique) déconseillent les mécaniques qui exploitent la comparaison sociale ou la peur de perdre (M20).

## Décision
- Points d'expérience, niveaux, badges d'un catalogue fixe, séries **hebdomadaires** (et non quotidiennes).
- Une semaine inactive par mois met la série en pause, sans la remettre à zéro.
- **Aucun classement** ni aucune comparaison entre élèves, même au sein d'un groupe.
- Aucune notification de gamification hors de l'application ; aucune récompense aléatoire.
- Les récompenses saluent l'effort et la progression (cours terminé, copie rendue, compétence acquise), pas seulement la réussite.
- Le parent voit les mêmes récompenses que l'enfant.
